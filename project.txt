/*
# Secure Progressive Delivery Platform – Architecture Design

## Terraform Layer (Infrastructure Provisioning)

Terraform provisions and manages the complete AWS infrastructure.

### AWS Infrastructure Components

#### Networking

* VPC
* Public Subnets
* Private Subnets
* Internet Gateway
* NAT Gateway
* Route Tables
* Security Groups

#### Kubernetes Platform

* Amazon EKS Cluster
* Managed Node Groups / Karpenter

#### Identity & Access

* IAM Roles
* IAM Policies
* OIDC Provider
* IRSA (IAM Roles for Service Accounts)

#### Container Registry

* Amazon ECR Repository

#### Storage

* Amazon S3 Bucket

  * Loki log storage
  * Backup storage
  * Artifact storage

---

# GitOps Layer (Managed by Argo CD)

Argo CD continuously syncs Kubernetes manifests from GitHub to the EKS cluster.

## Argo CD Managed Components

### Ingress & Traffic Management

* AWS Load Balancer Controller (ALBC)

  * Creates Application Load Balancer (ALB)
  * Manages ingress routing

### Logging Stack

* Loki

  * Centralized log aggregation
  * Stores logs in S3

* Fluent Bit

  * Collects pod and node logs
  * Ships logs to Loki

### Progressive Delivery

* Argo Rollouts

  * Canary deployments
  * Blue-Green deployments
  * Automated rollback support

### Application Deployments

Applications deployed through GitOps:

* Frontend application
* Backend API
* Database manifests (if required)

---

# CI/CD Flow

## CI Pipeline – GitHub Actions

When a developer pushes code:

1. GitHub Actions pipeline starts
2. Security scans execute:

   * Gitleaks
   * Checkov / tfsec
   * SonarQube
   * Trivy
3. Docker image is built
4. Image is pushed to Amazon ECR
5. Kubernetes manifests / Helm values are updated with new image tag
6. Changes are committed to GitOps repository

---

# CD Flow – Argo CD

1. Argo CD detects Git changes
2. Synchronizes manifests to EKS
3. Argo Rollouts performs progressive deployment
4. ALBC routes traffic
5. Prometheus monitors rollout health
6. Automatic rollback triggers if failures occur

---

# Monitoring & Observability

## Monitoring

* Prometheus collects metrics
* Grafana visualizes dashboards

## Logging

* Fluent Bit collects logs
* Loki stores logs
* Grafana visualizes logs

---

# High-Level Deployment Flow

Developer Push
↓
GitHub Actions CI
↓
Security Scanning
↓
Docker Build
↓
Push Image to ECR
↓
Update GitOps Repository
↓
Argo CD Sync
↓
Argo Rollouts Progressive Deployment
↓
ALBC Routes Traffic
↓
Prometheus + Grafana Monitoring
↓
Automatic Rollback if Failure Detected


*/
